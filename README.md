# create-aws-alias


## Aim of script.


This script aims to make it easier to just create an alias for logging into AWS. 


## I need you to:


Please configure sso before use **aws configure sso**. You will also need to remember the profile name you have used to configure this sso sign in. 


You can check this at ~/.aws/config (You can use **grep profile ~/.aws/config** to list profile names you have created)


maybe at a later date we can automate this step :)
